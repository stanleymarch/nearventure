# Приёмка беты 0.1

Этот чек-лист фиксирует доказательства готовности внутренней беты, а не объявляет
публичный релиз. Отмечать пункт можно только ссылкой на результат конкретного
прогона, аудит или ревью. Результаты и их границы зафиксированы датированными
операторскими наблюдениями (2026-08-1x).

## Зафиксированная база

- [x] Канонический сбор, нормализация, дедупликация, quality gates и export POI
  принадлежат внешнему [poi-toolkit](https://github.com/stanleymarch/poi-toolkit).
  Nearventure принимает только его bundle через manifest-валидируемый импортёр;
  прямой SQL и встроенные сборщики не являются допустимым путём обновления.
  Граница и локальная C6/C7 приёмка зафиксированы датированным операторским
  наблюдением (2026-08-1x).
- [x] Оператор зафиксировал production C6-аудит `pfo-v0.1-v1`: dry-run и
  финальный импорт с run-dir `releases/pfo-v0.1-v1`, атомарный отказ первого

## Операционная проверка POI-импорта

- [ ] Оператор подготовил новый bundle во внешнем `poi-toolkit`, проверил его
  provenance и manifest; тег и контрольные суммы сохранены в release evidence.
- [ ] Bundle помещён в `/srv/nearventure/imports/releases/<tag>/`; trusted root
  принадлежит root, bundle защищён от записи, а mount доступен read-only только
  одноразовому сервису `poi-importer`.
- [ ] До записи сделан резервный `pg_dump` и успешен обязательный dry-run:
  `docker compose --env-file docker/.env.prod -f docker/docker-compose.prod.yml --profile import run --rm poi-importer --dry-run --run-dir releases/<tag>`.
- [ ] После ревью dry-run выполнен обычный import с тем же `--run-dir`; проверены
  запись `poi_import_audit`, версия/контрольная сумма manifest и число POI. Replay
  не разрешается без явного `--allow-replay` и проверки аудита.
- [ ] Проверка API подтверждает ожидаемый каталог; результаты и имя bundle
  приложены к release evidence. При проблеме восстановить предимпортный backup,
  а не выполнять ad-hoc SQL.

## Ограничения беты и внешние owner gates

- [ ] В заметках к бете указано, что карта не полностью self-hosted. Web-карта
  использует локальную PMTiles-подложку только в обычных векторных стилях, но
  загружает внешние glyph/sprite Protomaps; спутниковый слой — ArcGIS World
  Imagery, вело- и пеший overlays — CyclOSM и Waymarked Trails, а рельеф — AWS
  Terrain Tiles. Mini App запрашивает Leaflet-тайлы same-origin по
  `/raster-tiles/`, однако nginx проксирует их к CyclOSM: это не делает источник
  тайлов локальным. Доступность и условия этих провайдеров — внешняя зависимость.
  До закрытия пункта сохранить результаты реального рендеринга Web на desktop и
  mobile и Mini App в целевой Telegram-среде; существующие API/routing health
  наблюдения этого не доказывают.
- [ ] **Owner gate — Telegram:** владелец предоставил действительный replacement
  bot token и выполнил device acceptance. Этот пункт не закрывается документацией
  или CI.
- [ ] **Owner gate — GitHub:** после ротации секретов владелец подтвердил чистый
  публичный baseline и secret scan. До этого публичный GitHub release запрещён.
